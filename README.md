# Apple Archery

Game panahan 2D bergaya kartun modern. Dibangun dengan Godot 4.x dan GDScript, target utama Android. Developer: Naze.

Pengembangan mengikuti metode Spec-Driven Development. Dokumen SDD berada pada direktori docs/SDD/:

- 00-SPEC.md — spesifikasi requirement
- 01-ARCHITECTURE.md — arsitektur
- 02-DECISIONS.md — decision records
- 03-BACKLOG.md — task breakdown per fase
- 04-TEST-PLAN.md — rencana pengujian
- 05-TRACEABILITY.md — matrix keterlacakan
- 06-RISKS.md — register risiko
- PHASE0_REPORT.md — laporan audit dan baseline

Status: Phase 0 selesai; menunggu persetujuan untuk Phase 1 (vertical slice).
